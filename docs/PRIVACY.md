# 隐私说明

24π 在设备本地记录应用使用、通知事件、地点停留、原始定位点、步数和采集缺口。各可选来源可在首次使用时跳过，并在设置中调整。

## 本机保存

记录保存在应用沙盒中的 Room 数据库，系统备份关闭。数据库不额外加密，设备访问保护依赖 Android 的文件加密与锁屏。

通知标题、正文默认不读取；开启内容保存需要用户单独确认。关闭开关不删除已有档案。历史记录在应用内永久保留，不自动清理。

用户主动创建的备份使用密码加密。CSV 是可读明文；Observe 构建的诊断包包含日志、时间、应用信息及模糊位置等敏感线索，分享前需要检查内容和接收方。

## 联网行为

- 地点名称反查：启用后，系统地理编码及备用服务可能接收停留中心坐标；与在线地图分别设置。
- 高德在线地图：用户单独启用后创建地图视图，SDK 可能处理必要设备、网络和查看区域信息，见 [地图说明](MAP_PRIVACY.md)。
- AI 回顾：用户选择服务、模型与 API Key，预览聚合摘要后主动发送。摘要可能包含地点名称、应用名称、时长、通知数量和用户问题，不默认发送原始坐标、轨迹点或通知正文。服务提供方会接收预览内容及请求所需的身份信息。

AI Key 通过 Android Keystore 加密后保存在不参与备份的目录，不进入本应用的档案备份、CSV 或诊断包。测试连接仅发送测试消息。

项目没有账号、自建云同步、广告、行为分析或第三方崩溃上报。使用任何联网功能仍需阅读对应服务的数据处理规则。

## 公开反馈

仓库只接受合成或已充分脱敏的复现材料。不要上传个人数据库、导出、诊断包、通知正文、精确位置、密钥或带有个人内容的截图。安全问题通过 [私密渠道](../SECURITY.md) 报告。
