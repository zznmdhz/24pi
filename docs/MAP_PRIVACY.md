# 在线地图与本机档案

0.18.0 提供可选高德地图。首次进入地图页单独启用，地图页可停用。未启用时不创建地图视图。

高德底图需要联网。SDK 可能处理必要的设备/网络信息、地图请求区域与查看位置等信息，以高德隐私说明为准：https://lbs.amap.com/pages/privacy/ 。启用地图不等于开启地点名称反查，二者设置独立。

应用不建立轨迹云账户，不调用猎鹰轨迹上传或导航规划补路。原始位置历史继续保存在本机；这一点不代表在线地图完全不向 SDK 服务传递地图相关信息。

采集继续使用现有系统定位，地图不会启动另一套高频采集。位置卡片显示测量时间和精度，旧位置明确标为最后记录。

地图不可用时可返回行程文字列表及本机轨迹预览。原始 CSV、加密备份和地点修订仍由现有导出/备份入口管理。
